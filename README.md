---

## 🚀 **O que estou construindo**

### 💬 Perfoster Connect — Comunicação Empresarial
SaaS multi-tenant e multicanal de atendimento via WhatsApp, com:
- **Backend:** NestJS 10 · Prisma · PostgreSQL 16 · Redis + BullMQ · Socket.IO
- **Frontend:** Next.js 14 (App Router) · TypeScript
- **Integrações:** Evolution API v2 · Meta Cloud API (Embedded Signup aprovado pela Meta)
- **Infra:** Docker Compose · VPS · Nginx

### 🤖 Agentes de IA & Automações
Desenvolvimento de agentes inteligentes e fluxos de automação com **n8n**, **MCP (Model Context Protocol)** e arquitetura multi-agente, aplicados a operações reais de empresas.
